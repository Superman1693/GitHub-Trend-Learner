# 六模块输出模板

> **用途**：所有仓库解读输出必须套用本模板，保证结构统一。
> **结构权威来源**：`global.md` §2.1。本模板与 `global.md` 冲突时，以 `global.md` 为准。
> **原则**：结构固定，内容定制——六个模块不可增删改名，模块内部内容按项目类型（工具 / AI 模型 / 框架 / 脚本 / 项目模板 / 其他）调整重点。
> **v1.5 变更**：原 M6「部署与使用常见报错大全」已删除，原 M7 前移为 M6；M5 强化为「可运行 + 小白分步」。

## 模块无适用内容时的写法

若某模块确实不适用（例如纯文档/资源汇总类项目没有可运行的部署流程），**不得删除模块**，按以下写法处理：

```markdown
## 五、本地一键部署完整方案

本项目暂未发现该类问题，以下为同类项目通用提示：
<给出通用内容，不得留空>
```

> **M5 特别说明**：即使项目本身无需「部署」（如纯文档仓库），也**不得跳过 M5**——应改写为「如何获取并使用该项目」（克隆/下载/阅读方式），保持六模块完整（`global.md` §2.3）。
